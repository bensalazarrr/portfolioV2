## What it is

A frontend-only concept for a neighbourhood café: menu, story, gallery, and contact, with all brand, address, and review content intentionally fictional.

## Design

Dark stone background, cream serif display type, and a single warm accent. The hero photograph is the only image above the fold, so it carries the page.

## Build

Next.js App Router with TypeScript, Tailwind CSS on a semantic token system, Framer Motion, and React Hook Form with Zod for the contact form.
